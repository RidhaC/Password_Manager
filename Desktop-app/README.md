# Access Guardians 

Here is the Desktop-App that we will be using 


## How to

Download and install the password manager app. 

Open the application located in the "dist" folder.

When the app starts, the welcome screen appears with two options: Create an account and log in.
If this is your first time using the app, select Create an Account.

Enter your username.
Create a master password that is at least 16 characters long and includes uppercase letters, lowercase letters, numbers, and symbols.
You can also use the built-in password generator to automatically create a strong password that meets the policy.
Confirm the password, then click Create Account.

After creating an account, you will be redirected back to the login page.
Enter the username and master password to unlock the vault.
The vault will be empty at first because no credentials have been stored yet.

When finished, select "logout" to securely exit.
The system will securely lock the vault to prevent unauthorized access.
